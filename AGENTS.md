# AGENTS.md - Open in EduIDE browser extension

Chrome extension that adds "Open in EduIDE" to GitHub's Code menu and opens the landing page of an installation with the repository and a matching template preselected.
See `README.md` for install, tests and layout.

## Terminology

Use the terms of the [EduIDE glossary](https://eduide.github.io/Docs/glossary) in code, UI texts, docs, values and comments, in exactly the meaning it gives.
Do not introduce synonyms (environment, instance, workspace, launch, lecturer, start page) for a term the glossary defines, and never write "frontend" or "backend".
When a new term is needed or a term changes, update the glossary in `EduIDE/Docs` first.
Most relevant here: template (the language choice maps to a template name, sent as the `appDef` URL parameter, which stays for Artemis), installation, landing page, session.
