Language → image

The repository's main language picks the image. Languages without one open the landing page's language picker. Override as JSON: an app id maps a language, an empty string removes a default. App ids must exist on the installation, or the landing page shows "Invalid default selection value".

Git hosts

The toolbar button opens repositories on github.com, gitlab.com and codeberg.org. Add a self-hosted server with one line each, host gitlab or host gitea (Forgejo counts as Gitea). The EduIDE installation must also allow the host.
